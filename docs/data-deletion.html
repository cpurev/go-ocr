Data Deletion Instructions

Last updated: 7 August 2026

This page explains how to have your data deleted from go-ocr, a personal, non-commercial receipt-scanning project. What is stored is described in the privacy policy.

How to request deletion

  1. Send an email to hello@talendary.com with the subject Data deletion request.
  2. Include the WhatsApp phone number you used to send receipts, in full international format (for example +976XXXXXXXX). That number is the only key linking the stored records to you, so the request cannot be fulfilled without it.
  3. Alternatively, send the message DELETE MY DATA over WhatsApp from that same number.

What gets deleted

Every receipt record associated with your WhatsApp number is permanently removed from the database: the extracted merchant, total, date, currency, tax and line items, the raw OCR text, the WhatsApp media identifiers, and the phone number and any group identifier themselves. Nothing is retained in an anonymized or aggregated form.

Receipt images are never stored in the first place. They are held in memory only while the text is being read, so there is no image to delete.

How long it takes

Requests are handled within 30 days, and normally much sooner. You will get an email confirming the deletion once it is done.
