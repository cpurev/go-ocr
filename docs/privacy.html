Privacy Policy

Last updated: 7 August 2026

This policy covers go-ocr, a personal, non-commercial receipt-scanning project operated by an individual. It is not a company product, it carries no advertising, and it has no users beyond those the operator explicitly invites.

What the service does

You send a photo of a receipt to a WhatsApp number. The service downloads that image, reads the text on it using optical character recognition, extracts the fields that matter (merchant, total, date), and stores the result so it can be searched later.

What is collected

Only what arrives with a message you choose to send:

  • Your WhatsApp phone number, as supplied by WhatsApp with the message
  • The WhatsApp group identifier, if the receipt was sent in a group
  • The WhatsApp media identifier for the image
  • Text read from the receipt image: merchant, total, date, currency, tax, line items
  • The full raw OCR text of the image, kept so mistakes in the extraction can be corrected
  • The time the record was created

No contact list, no location, no device identifiers, and no profile information are collected. Nothing is gathered from you except messages you deliberately send.

Where the image itself goes

The image is held in memory only for as long as it takes to read the text from it. Text recognition runs locally on the operator's own machine using Tesseract, and the image is never uploaded to any third-party OCR or AI service. The image file is not written to disk and not retained; only the extracted text is stored.

Who it is shared with

Nobody. The extracted data is not sold, rented, shared, or used for advertising, profiling, or training any model. Two service providers necessarily handle data in transit or at rest:

  • Meta / WhatsApp: delivers your message and hosts the image until it is downloaded, under Meta's own privacy policy
  • MongoDB Atlas: stores the extracted receipt records

Data may also be disclosed if required by law.

How long it is kept

Receipt records are kept until you ask for them to be deleted, or until the project is shut down, at which point the database is destroyed.

Deleting your data

See the data deletion instructions. In short: message or email the operator from the WhatsApp number you used, and everything associated with that number is removed within 30 days.

Children

The service is not directed at anyone under 16 and is not knowingly used by them.

Changes

If this policy changes, the revised version is published at this URL with a new date at the top.
